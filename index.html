📖 How to use

  • Home: shows your live fasting timer, or last night's fast and your best. Log meals below it.
  • Charts: fasting hours, weight vs target, dinner times and summary cards.
  • History: all days; tap one to edit.
  • Water, black coffee, green tea and ACV never break the fast.
  • Fast colours: red < 12h, amber 12–14h, green 14–16h (sweet spot), purple > 16h.

☁️ Set up private backup (one time)

Your data is stored in a private GitHub Gist so it survives a cleared browser, a phone reset or a new phone.

  1. Open github.com/settings/tokens/new (Tokens → classic).
  2. Name it Fasting tracker, set Expiration to No expiration, and tick only the gist scope.
  3. Click Generate token and copy it (starts with ghp_). It is shown only once.
  4. Save the token in a password manager – you need it on a new phone.
  5. In this app go to Settings → Backup & sync, paste the token, leave Gist ID blank, tap Save & sync.
  6. The status should say Synced and the red banner disappears. A private gist named meal-data.json is created automatically.

After that every save is backed up automatically. If you are offline, data stays on the phone and syncs later.

📱 Restore on a new phone

  1. Open the app URL and install it (see below).
  2. Settings → paste the same token, leave Gist ID blank → Save & sync.
  3. The app finds your existing gist and restores all your history.

Lost the token? Create a new one, and paste your Gist ID (find it at gist.github.com, in the gist's URL) into the Gist ID box.

📲 Install as an app

  • Android (Chrome): Settings tab → Install app, or Chrome menu ⋮ → Install app / Add to Home screen.
  • iPhone (Safari): Share button → Add to Home Screen.

🛟 Extra safety

  • Use Export JSON in Settings now and then as an offline copy.
  • The gist keeps revision history on GitHub, so older versions can be recovered.
  • Never share your token. Use Forget token on a phone you give away.
